# WhatsApp UI Clone (React Native / Expo)

Tento projekt je statický vizuální klon (demo) uživatelského rozhraní mobilní aplikace WhatsApp. Slouží pro studijní účely, trénink frontendu a rozvoj v oblasti vývoje mobilních aplikací pomocí **React Native** a **Expo**.

⚠️ **Upozornění:** Nejedná se o reálnou komunikační aplikaci ani o žádný oficiální produkt společnosti Meta. Jde pouze o grafický návrh a front-endový náhled rozhraní.

---

## 🚀 O projektu
Cílem tohoto projektu bylo vyzkoušet si:
* Vytváření responzivního mobilního rozhraní v React Native.
* Stylování prvků, ikon a tmavého režimu (Dark Mode) inspirovaného skutečným WhatsAppem.
* Práci s lokálními daty pro zobrazení seznamu chatů a zpráv.

## 🛠️ Použité technologie
* **React Native**
* **Expo**
* **JavaScript**
